# Student Study Planner

A beginner-friendly study planner made with HTML, CSS, and JavaScript. It runs locally in your browser and does not need paid tools or a server.

## Features
- Add a study task, subject, and due date
- Mark tasks as completed
- Delete individual tasks
- Clear all completed tasks
- Automatically save tasks in browser local storage
- Responsive layout for phones and computers

## How to run
1. Download and extract the ZIP file.
2. Open the `student-study-planner` folder.
3. Double-click `index.html` to open it in your browser.

## Files
- `index.html` — page structure
- `style.css` — design and layout
- `script.js` — task interactions and saving
- `README.md` — project instructions

## GitHub upload
1. Create or open your repository named `student-study-planner`.
2. Choose **Add file → Upload files**.
3. Upload `index.html`, `style.css`, `script.js`, and `README.md`.
4. Commit the changes.

## Note
Tasks are saved in the browser you use. They are not synced across devices or accounts.
